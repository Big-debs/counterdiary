Since your platform is an **anonymous confessions diary + survey + heat map**, your asset choices should reinforce three emotional pillars:

* **Safety** (anonymous, no judgment)
* **Honesty** (raw confessions, real struggles)
* **Local relevance** (Nigerian food ecosystem context)

You also need **lightweight, mobile-optimized, SVG-first assets**.

Here is a curated stack of the best **asset libraries for images, SVG icons, effects, and transitions**, plus how each fits your product specifically.

---

# 1️⃣ SVG Icon Libraries (Top Priority)

SVG icons will define most of your UI personality.

## ⭐ Best Overall: Lucide

**Why it's perfect:**

* Clean, modern, emotionally neutral (important for anonymous platform)
* Lightweight SVG
* Works beautifully on mobile
* Open source
* Easy to style with CSS

**Perfect icons for your app:**

* message-circle → confessions
* map → heat map
* send → submit entry
* flame → trending hotspots
* shield → anonymous safety
* eye-off → anonymity
* clock → daily entries

**CSS styling example:**

```css
.icon {
  stroke: var(--primary-green);
  stroke-width: 1.8;
}

.icon-alert {
  stroke: var(--alert-red);
}
```

---

## ⭐ Second Option: Phosphor Icons

**Why it’s excellent:**

* Friendly and expressive
* Multiple weights (thin, regular, bold)
* Great for emotional UI

Use thin weight for neutral UI, bold weight for alerts.

---

## ⭐ Third Option: Heroicons

**Best if using Tailwind**

Very clean, modern, professional feel.

---

# 2️⃣ Illustration Libraries (Anonymous Confession Friendly)

Illustrations should reinforce:

* anonymity
* reflection
* emotional safety
* community

Avoid overly playful cartoon styles.

---

## ⭐ Best Overall: unDraw

**Why perfect:**

* Anonymous-friendly abstract people
* Editable SVG colors
* Modern, tech-aligned
* Lightweight

Use for:

* Empty confession wall
* No data states
* First onboarding

Example:

* person writing illustration
* map exploration illustration

---

## ⭐ Excellent Alternative: ManyPixels

Slightly warmer and more human feeling.

Better for:

* onboarding screens
* trust building

---

# 3️⃣ SVG Pattern Libraries (For Cultural Texture)

Subtle background patterns inspired by African textiles work well—but must be subtle.

---

## ⭐ Best Pattern Library: Hero Patterns

Use at very low opacity:

```css
.confession-section {
  background-image: url('/pattern.svg');
  opacity: 0.04;
}
```

This adds depth without distraction.

---

## Alternative: SVG Backgrounds

Lets you generate custom patterns matching your color palette.

# 4️⃣ Mapbox Enhancement Assets (Critical for Heat Map UX)

Since you're using Mapbox, combine it with:

## ⭐ Marker Icons: Mapbox Maki Icons

You can customize markers for:

* Confession clusters
* Problem hotspots
* High-activity zones

---

Add CSS glow animation:

```css
.map-marker-hot {
  animation: glow 1.5s infinite;
}

@keyframes glow {
  0% { filter: drop-shadow(0 0 0px red); }
  50% { filter: drop-shadow(0 0 8px red); }
  100% { filter: drop-shadow(0 0 0px red); }
}
```

# 6️⃣ CSS Transition Presets (For Mobile Fluidity)

Add these transitions globally:

```css
.card {
  transition: transform 0.2s ease,
              box-shadow 0.2s ease,
              opacity 0.2s ease;
}

.card:active {
  transform: scale(0.98);
}
```

```css
.button {
  transition: all 0.15s ease;
}

.button:active {
  transform: translateY(1px);
}
```

---
